## ⚙️ Foco de Atuação e Boas Práticas

- **Performance e Query Tuning:** Diagnóstico de gargalos, análise de planos de execução e otimização estrutural de índices para redução do tempo de resposta (I/O) e minimização de *locks*.
- **Arquitetura e Regras de Negócio:** Desenvolvimento de *Stored Procedures*, *Views* e *Functions* para processamento de lógicas transacionais complexas diretamente no servidor de banco de dados.
- **Segurança da Informação:** Implementação de controle de acesso (RBAC - *Role-Based Access Control*), criptografia e sanitização de dados, seguindo rigorosamente as documentações oficiais da Microsoft e Oracle.
- **Infraestrutura de Dados:** Conteinerização de ambientes de banco de dados e aplicações utilizando Docker, garantindo paridade entre desenvolvimento, homologação e produção.
